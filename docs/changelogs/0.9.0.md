# Steadfast 0.9.0

Steadfast 0.9.0 brings Minecraft 26.3 support alongside significant visual
upgrades to water, lighting, and the sky on most profiles.

## Minecraft 26.3 support

* Added foliage effects to Wilderness Bound blocks, including Poplar leaves
* Added support for the new enchantment glint rendering method on 26.3+

## Sky

* The sun and moon now fade below the horizon, leading to much more convincing
  and realistic sunsets and sunrises
* Stars now smoothly fade in and out during sunsets / sunrises
* Make the horizon on Semi-Natural a bit less bright
* Fixed a bug causing the Pale Garden sky to turn white due to it falsely being
  detected as stars
* Added an option to reduce the coverage of cirrus clouds
* Cirrus clouds are now enabled by default with reduced coverage
* Fixed odd blending between cirrus clouds and the sun

## Water

* Shallow water is now very clear instead of being excessively blue/turqoise,
  and has a generally more realistic color
	* Enabled support for physically-based water absorption coefficients
	* Replaced the default water absorption coefficients with ones for much more
	  clear water
	* Added water scattering to simulate dirt and other impurities in water
	* Water absorption is now based partly on the distance through the water
	  volume travelled, instead of just the vertical depth to the water surface
	  at that point
	* The fantasy profile retains the older water absorption method as it
	  matches that visual style.
* Added enabled-by-default rough refraction to improve visibility of clear water
* Water now uses a physically-accurate Fresnel F0 value
* Significantly improved the shading of underground water
* Significantly improved the shading of flowing water
	* Previously, only completely flat water surfaces had reflections /
	refraction / absorption / waves / etc, and flowing water used the
	vanilla water texture.
* Improved the shading of the water surface when underwater
* Fixed ugly artifacts at the horizon when underwater

## Lighting

* Added physically-based block light colors based on blackbody color temperature
  and made the default color 3000K (yellow) rather than 2000K (orange)
	* This replaces the previous orange/less orange blocklight color toggle.
	* You can select color temperatures between 250K to 12000K
	* Also added a non-physically based purple light color, for testing colored
	  lighting algorithms
* Significantly reduced the level of ambient occlusion applied to direct light
  to avoid excessive shadowing in direct sunlight/moonlight.
* The night desaturation (purkinje) effect now fades away during twilight.
	* In my opinion this gives the best of both worlds between having this
	  option disabled and having it enabled. Previously night desaturation would
	  quickly fade away as the sun set, which wasn't very realistic.

## PBR and Resource Pack support

* Added optional (disabled by default) integrated PBR for crying obsidian behind
  the "Detect common emissives" option
* Added optional support for ambient occlusion and normal mapping with PBR
  resource packs.
* Other PBR resource pack features remain unsupported at this time, but are
  planned for the future.


## Shader settings

* Improved the shader options screen with additional options, and gave existing
  ones meaningful names
* Added an option under Development / Debugging to fix lighting with Create
  Aeronautics, currently disabled by default due to performance impact.
* Fixed a potential shader compile error when water caustics are disabled


## Performance

* Steadfast 0.9 has the same performance as 0.8 with the same settings.
	* Steadfast 0.9 has more features enabled by default for some minimal
	  performance impact.
* Improved performance on the Retro profile caused by duplicate fog calculations
	* This was actually caused by a misguided optimization that tried to turn
	  off the separate fog pass which didn't work properly. The fix was to
	  always use the separate fog pass instead.


## Internals

* Significantly refactored the internal code structure in preparation for adding
  an Aperture implementation alongside the existing Iris format implementation
